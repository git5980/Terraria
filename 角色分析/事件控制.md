# 泰拉瑞亚事件总表与触发方法

> 数据来源：JsHook 注入游戏进程，枚举 `Terraria.Main` 全部静态字段 + `Terraria.GameContent.Events` 命名空间（11 个类）+ 全镜像类名扫描（142 个事件相关类）。
> 配套文件：`event_ops.js`（执行脚本）、`events.json`（38 套触发模板）。
> **当前世界状态**（2026-09-17 扫描）：无任何事件进行中；`hardMode=false`（未进困难模式）；`invasionType=0`；`dayTime=true`。

---

## 一、怎么用（三步）

1. 保证脚本下发服务在跑：
   ```bash
   cd "/sdcard/Download/DSHA/泰拉瑞亚项目/角色分析" && nohup python3 -m http.server 8791 --bind 127.0.0.1 &
   ```
2. 改 `event_ops.js` 顶部两行：
   ```js
   action: "血月-开",   // 模板名，见第五节；留空则只扫描
   enabled: false,      // 先 false 跑一遍确认；确认后再改 true
   ```
3. 在 JsHook 里执行 `http_eval.js` 的内容（它会拉最新脚本进游戏进程）。

也可以绕过模板直接写：
```js
set:  { "Main.bloodMoon": true }                                  // 直写静态字段
call: [ { target:"Main", method:"StartInvasion", args:[1] } ]     // 直调方法
```

## 四、入侵类事件

`Main.invasionType` 取值（`Terraria.ID.InvasionID` 常量实测）：

| 值 | 事件 |
|---|---|
| 0 | None（无） |
| **1** | **GoblinArmy 哥布林入侵** |
| **2** | **SnowLegion 雪人军团** |
| **3** | **PirateInvasion 海盗入侵** |
| **4** | **MartianMadness 火星暴乱** |

**触发**：`Main.StartInvasion(int type)` → 脚本模板 `哥布林入侵` / `雪人军团` / `海盗入侵` / `火星暴乱`
**停止**：直写 `Main.invasionType=0` `Main.invasionSize=0` `Main.invasionDelay=0`（模板 `入侵-停`）
**相关字段**：`invasionSize`（剩余怪物数）`invasionX`（进度）`invasionWarn` `invasionSizeStart` `invasionProgress*`

### 撒旦军队（旧日支配者军团）`DD2Event`

状态：`Ongoing=false` `OngoingDifficulty=0` `DownedInvasionT1/T2/T3=false` `WonThisRun/LostThisRun=false`

| 操作 | 方法 |
|---|---|
| 开始（T1/T2/T3） | `DD2Event.StartInvasion(int tier)` → `[1]`/`[2]`/`[3]` |
| 停止 | `DD2Event.StopInvasion(bool)` |
| 直接召唤水晶 | `DD2Event.SummonCrystal(int x, int y, int npc)` / `SummonCrystalDirect(...)` |
| 召唤 Boss（双足飞龙） | `DD2Event.SummonBetsy()` |
| 清场 | `DD2Event.ClearAllDD2HostilesInGame()` / `ClearAllTowersInGame()` / `ClearAllDD2EnergyCrystalsInGame()` |
| 重置进度 | `DD2Event.ResetProgressEntirely()` |

## 十、风险

1. **会真实改变世界**：血月/日食/入侵/沙尘暴都会立刻刷怪；正处中核难度（`difficulty=1`）时死亡掉物品。
2. **先备份存档**：`/sdcard/Android/data/com.xd.terraria/`（旧存档在 `OldSaves/`）。
3. **入侵类建议用模板停止**：`入侵-停` / `撒旦军队-停` / `全部停止`，比等它自然结束干净。
4. **不要同时叠多个入侵**：`Main.invasionType` 只有一个字段，同时开两个会互相覆盖。
5. 脚本默认 `enabled=false`，**不主动触发任何事件**。
