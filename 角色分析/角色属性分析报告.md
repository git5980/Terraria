## 二、分项分析

### 1. 生命与魔力：完全未成长
`statLife 100 / statLifeMax2 100`、`statMana 20 / statManaMax2 20`。
- 生命水晶（+20 上限 ×15）与生命果（+5 ×20）都没吃，魔力水晶（+20 ×9）也没吃。
- 也就是说：**这是刚创建不久的角色体型**（或从未做过生命提升）。

### 2. 防御：真·裸装
`statDefense = 0`，且装备数组全部为空：
- `armor`（20 格：护甲 3 + 饰品 7 + 时装 10）→ **空**
- `dye`（10 格染料）、`miscEquips`（5 格杂项）、`miscDyes` → **空**

所以没有任何护甲防御、没有饰品加成、也没有时装（外观是默认外观：发型 21）。

### 3. 战斗：只有基础值
- 四类伤害倍率都是 1.0，暴击全是 4%（游戏基准）。说明既没有伤害类饰品，也没有增益药水。
- 背包里唯一能打的是**钱币枪（ID 905）**——它的伤害由弹药（金币）价值决定，配合 9460 铂金币会打出极高伤害；但**角色本身没有任何战斗加成**，完全依赖这把枪。

### 4. 机动：只有向日葵的 10%
- `moveSpeed 1.21`、`maxRunSpeed 3.63`、`accRunSpeed 3.0`：无赫尔墨斯靴/闪电靴，跑不快。
- `wingTime 0 / wingTimeMax 0`：**没有翅膀，不能飞**。
- `dashType 0`：无冲刺；`autoJump false`：无自动跳跃。
- 移动相关的 1.21 主要来自向日葵增益（+10% 移动速度），增益一消失就掉回 1.1 左右。

### 5. 生存：无任何抗性
`endurance 0`（无减伤）、`immuneTime 0`（无无敌帧）、`lavaImmune false`（碰岩浆即死）、`shimmerImmune false`、`breath 200`（未延长水下呼吸）。中核难度下死亡会掉光背包——**背包里那 9460 铂金币风险极高**。

### 6. 状态
- 减益：**无**（未中毒/着火/诅咒等）。
- 增益：仅 `buff#146 = Sunflower`（向日葵），且只剩 1 帧——拍快照时角色正站在向日葵旁边。

## 四、关键机制发现（决定了能怎么改）

实测 `Player.ResetEffects()` **每秒被调用 60 次**（3 秒 181 次），它会把下面这些字段**每帧重新算一遍**：

| 类别 | 字段 | 直接写一次的后果 |
|---|---|---|
| 防御 | `statDefense` | 立刻被覆盖回 0 |
| 伤害倍率 | `meleeDamage` `rangedDamage` `magicDamage` `minionDamage` | 被覆盖 |
| 暴击 | `meleeCrit` `rangedCrit` `magicCrit` | 被覆盖 |
| 移动 | `moveSpeed` `maxRunSpeed` `accRunSpeed` `jumpSpeedBoost` | 被覆盖 |
| 翅膀 | `wingTime` `wingTimeMax` | 被覆盖 |
| 其它 | `luck` `endurance` `immuneTime` | 被覆盖 |

而**基础字段写一次就能留住**：`statLifeMax` `statLife` `statManaMax` `statMana` `difficulty` `breath` 等。

> 结论：想改「防御/伤害/暴击/移速」这类属性，必须 **Hook `ResetEffects`，在它跑完之后每帧重写**；
> 想改「生命上限/魔力上限/难度」这类基础属性，直接写一次即可。
> 具体操作清单见同目录 `角色可用操作.md`，可执行脚本见 `player_ops.js`。

## 五、数据口径与限制

- 数值全部来自**运行时对象**，与你这台手机上安装的版本一致；不是攻略站的通用数据。
- `longInvincibility` 字段在本移植版**不存在**（已用 `onHitDodge` / `lavaImmune` / `shimmerImmune` 替代）。
- 增益名称无法通过 `Lang.GetBuffName` 正确取到（返回空的 LocalizedText），本报告用 `Terraria.ID.BuffID` 常量表解析，映射表见 `buff_ids.json`。
- 快照是**某一瞬间**的状态：生命值、坐标、增益会随游戏进行变化，其余结构性属性（上限、难度、装备）稳定。
