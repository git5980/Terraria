# 泰拉瑞亚修改技能包（可移植）

给**任意 AI agent 或人**复用：从零做泰拉瑞亚（Unity + IL2CPP）修改功能与游戏内修改器菜单。

## 怎么用

- **AI agent**：把 `SKILL.md`（中文）或 `SKILL.en.md`（英文）当技能正文加载（带 YAML frontmatter，`name: terraria-modding`）。
  **先读 `版本与时效.md`** 确认本机版本是否已变（变了就按里面的表重建对应数据）。
  需要细节时再读 `参考/踩坑清单.md`（34 条实测坑）与 `参考/菜单实现细节.md`（可直接抄的代码模式）。
- **人类**：先看 `成品/面板说明.md`（功能与用法），再看 `SKILL.md`（怎么做出来的）。

## 环境要求

- 目标游戏装在安卓设备上（本包按国服 `com.xd.terraria` 写，国际服同类）；
- **先读 `版本与时效.md`**：包内所有数字都是 **2026-09-19 / 国服 1.4.56002** 的快照，游戏更新后按那张表重建；
- JsHook 已开 MCP（`127.0.0.1:19820`），key 在 `/root/.dsh/jshook_key`；
- 图标：本包自带 `图集/atlas_{0,1}.png`，拷到 `/sdcard/Download/DSHA/terraria_icons/` 即可（游戏进程读不到 /sdcard 时，
  用 `脚本/图标HTTP服务.py` 起一次本地服务，菜单会把它们拉进游戏私有缓存）。

## 三条最短路径

```bash
# ① 直接装菜单
cd 成品 && python3 ../脚本/jshook.py exec --file 系统菜单.js --wait 7

# ② 只想知道某个功能怎么改（改字段/调方法）
grep -A2 '移速' SKILL.md

# ③ 游戏更新后重建图标/名字表
cd ../泰拉瑞亚项目/物品图标 2>/dev/null || cd /sdcard/Download/DSHA/泰拉瑞亚项目/物品图标
PYTHONPATH=/root/DshaWorks/pylibs python3 构建图标表.py && python3 注入图标表.py --write
```

## 路径配置（换目录/换设备必读）

- **游戏进程内**只有 2 个常量要改：`成品/系统菜单.js` 里 `ICON` 的 `var DIR`（图集本地回退目录）
  与 `var HTTP`（图集 HTTP 服务地址，端口要和 `图标HTTP服务.py` 一致）。
  图集**首选**来源是游戏私有缓存，路径由脚本 `getCacheDir()` 现算，不用改。
- **容器侧脚本**优先用环境变量：`ICON_DIR`、`ICON_LOG`（图标服务）、`JSHOOK_URL`、`JSHOOK_KEY_FILE`、
  `--package`（jshook）、`TASSETS`、`ICON_DST`（图标表/别名脚本）。
- **写死路径的 5 个脚本**（`注入图标表.py`、`生成名称表.py`、`补别名图标.py`、`extract_bundle.py`、
  `publish_to_github.py`）各只有一行，注释里写了它期望的目录关系；不想改代码就保持
  `控制面板/`、`物品库/`、`脚本/` 同级摆放。
- 改完自检：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8899/atlas_0.png` → 下发脚本 →
  日志出现「图标：图集 0 就绪 …（来源 私有缓存/HTTP）」。

**完整清单**（每个常量在第几行、每个脚本改哪一行、目录结构要求、四步自检）见 `成品/面板说明.md` 第十节。
